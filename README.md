🎬 YouTube UI Clone

A responsive YouTube UI Clone built using pure HTML and CSS, focusing on replicating the layout and design of a modern video streaming platform. This project highlights frontend design skills, including layout structuring, styling, and responsiveness.

🚀 Features
📺 YouTube-inspired user interface
📂 Sidebar navigation layout
🔍 Styled search bar
🎞️ Video grid with thumbnails
📱 Responsive design for multiple screen sizes
🎨 Clean and modern UI design
🛠️ Tech Stack
HTML5
CSS3 (Flexbox & Grid)

🎯 Purpose
This project is created to practice and demonstrate core frontend skills using HTML and CSS, with a strong focus on UI design and responsive layouts.

⚙️ How to Run
Clone the repository:
git clone https://github.com/Sido-dev/YouTube-Clone.git
Open index.html in your browser.
